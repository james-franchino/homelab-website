The hardware behind the lab

Meet Destiny and Daedalus.

My home lab runs on two servers with different strengths. Destiny focuses on storage and everyday applications. Daedalus gives me a dedicated Linux environment for running services and developing my administration skills.

Destiny: Storage and everyday services

Destiny runs Unraid, an operating system designed for network storage that can also run applications and virtual machines. It provides a central place for my files and hosts services I use regularly.

Hardware at a glance

  • Processor: AMD Ryzen 3 3200G
  • Memory: 32 GB RAM
  • Array drives: Four 10 TB hard drives
  • Operating system: Unraid
  • Power protection: CyberPower 1500VA UPS

The drives provide 40 TB of combined raw capacity. Usable storage depends on how much capacity is assigned to parity, which helps protect against drive failure. Parity does not replace a separate backup.

Destiny runs applications such as Plex for media, Immich for photos, and Paperless-ngx for documents. These services make the server useful beyond experimentation.

Daedalus: A dedicated Linux environment

Daedalus runs Rocky Linux. Working with this server lets me practice managing a Linux system directly, including using the command line, configuring services, and investigating problems.

Hardware at a glance

  • Processor: AMD Ryzen 9 5900X
  • Memory: 32 GB RAM
  • Graphics card: NVIDIA GeForce RTX 4060 Ti
  • Storage: 500 GB NVMe SSD and 2 TB SSD
  • Operating system: Rocky Linux

I use Docker and Docker Compose to run and configure applications on Daedalus. Containers package applications with the dependencies they need, making it easier to manage multiple services on one server.

Its workloads include system monitoring, utilities, and local artificial intelligence tools. The graphics card provides additional processing power for compatible AI workloads.

Connecting the lab

An ASUS RT-BE88U router connects the lab to my home network, while a Hitron CODA56 modem provides the connection to my internet service provider. The router allows my computers and other devices to reach the services running on the servers.

Networking is part of the learning experience. A running application is only useful if the devices that need it can connect to it reliably.

Why two servers?

The two systems give me different environments to learn from. Destiny combines storage management with useful applications, while Daedalus provides more direct experience administering a dedicated Linux server.

Together, they let me explore how hardware, operating systems, networking, and applications work together.
