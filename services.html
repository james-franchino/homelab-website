Putting the servers to work

Useful tools. Practical experience.

The hardware is only part of the lab. The applications running on it help me organize information, enjoy my media, and understand how my systems are performing.

What does self-hosting mean?

Self-hosting means running an application on a system you manage. In my lab, that means installing and maintaining services on my own servers and accessing them from my other devices.

This gives me more control over how those services operate, but it also makes me responsible for updates, configuration, backups, and troubleshooting.

Everyday applications

Plex

Plex organizes a personal media library and makes it available to compatible devices. I use it to browse and play media stored on Destiny.

Running a media server gives me experience with storage, file permissions, and network connectivity.

Immich

Immich provides a place to organize and browse my photos and videos. It helps me bring my personal photo collection together on my own server.

Managing it also reminds me that a photo application needs a backup plan for both its files and its database.

Paperless-ngx

Paperless-ngx helps organize digital documents into a searchable collection. It makes finding information easier than searching through folders of individually named files.

It is a practical example of using a server to keep everyday information organized.

Keeping track of the systems

Uptime Kuma

Uptime Kuma checks whether services are reachable. Its dashboard helps me spot availability problems and see when a service needs attention.

Portainer

Portainer provides a web interface for managing container environments. I use it to inspect containers and manage applications running in Docker.

Grafana and Prometheus

Prometheus collects system metrics, and Grafana displays them in dashboards. Together, they help me understand resource use and notice changes over time.

Experimenting with local AI

Daedalus also runs Ollama and Open WebUI. Ollama runs supported AI models locally, while Open WebUI provides a browser interface for interacting with them.

This part of the lab lets me explore how AI workloads use memory and processing power. It also gives me another application stack to configure and maintain.

How Docker fits in

Many of these applications run in Docker containers. A container packages an application with the software dependencies it needs, allowing multiple services to run on the same server.

Docker Compose lets me describe an application's configuration in a text file, including its storage and networking settings. Keeping that configuration organized makes the setup easier to understand and maintain.
